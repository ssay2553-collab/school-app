1. STAFF UTILITIES PORTAL (`/staff-dashboard`)
================================================================================
OVERVIEW:
The primary portal for general school staff members and support personnel. It
provides access to administrative support channels, daily financial recording tools
(if authorized), and event notifications.

KEY FEATURES & CONTROLS:
- Staff Header: Displays staff name, role tag, and administrative switch button (for admins).
- Staff Support Card: Direct chat link to communicate with school administration.
- Daily Financials Card (Permission-Based): Access point for recording feeding, bus, and extra lesson payments.
- Upcoming Events Banner: Real-time display of institutional events and term schedules.

HOW TO OPERATE:
1. Tap "Staff Support" to send an inquiry or message to school leadership.
2. Tap "Daily Financials" (if assigned financial permissions) to access fee collection tools.
3. Pull down on the screen to refresh notifications.

2. EDUCATOR CLASSROOM HUB / TEACHER METRO DASHBOARD (`/teacher-dashboard`)
================================================================================
OVERVIEW:
A Windows 8 Metro-style dashboard designed for teachers and subject educators. It
organizes daily teaching workflows into three main blocks: Classroom Hub, Teaching Tools,
and Campus Life.

KEY FEATURES & CONTROLS:
- Missing Attendance Alert Banner: Automatic pop-up alert warning teachers if daily attendance for their assigned class has not been marked between 6:00 AM and 10:00 AM.
- Classroom Hub Metro Tiles:
  * Attendance (Daily tracking)
  * My Classes (Subjects & arms setup)
  * Daily Financials (Feeding, Bus & Extra class collection - if permitted)
  * Timetable (Teacher schedule)
  * My Notes (Digital scratchpad)
  * Weekly Topics (Lesson planning)
- Teaching Tools Metro Tiles:
  * Term Records (Grade entry)
  * Exam Reports (Approved reports)
  * Behavioral Remarks (Conduct & skills)
  * Assignments (Upload & manage)
  * Grading (Mark student work)
  * Study Groups (Class channels)
  * Staff Attendance (GPS check-in)
  * Coding & Robotics (STEM projects)
  * Curriculum PDFs (Offline resources)
  * Pedagogy & Resources (Teaching aids)
- Campus Life Metro Tiles:
  * Calendar (Events & terms)
  * Broadcasts (School news)
  * Staff Chat (Staff messaging)
  * Parent Chat (Direct parent comms)
- Unread Notification Badges: Live counters for pending assignment submissions and parent messages.

HOW TO OPERATE:
1. Tap any Metro tile to launch the corresponding tool.
2. If the red "Attendance Missing!" alert is visible, tap "MARK NOW" to immediately take roll call.

3. DAILY CLASSROOM ATTENDANCE (`/teacher-dashboard/daily-attendance`)
================================================================================
OVERVIEW:
Allows classroom teachers to mark daily attendance for enrolled students, recording
presence, absence, lateness, or excused status.

KEY FEATURES & CONTROLS:
- Class Selector Dropdown: Choose from assigned class arms.
- Date Picker: Defaults to current day, with back-date capabilities (if permitted).
- Student Roster List: Displays student photo, full name, and interactive status buttons:
  * Present (Green)
  * Absent (Red)
  * Late (Yellow)
  * Excused (Blue)
- Batch Actions: "Mark All Present" button for rapid roll call.
- Remark Field: Input notes regarding illness or parental excuse.
- Submit Roll Call Button: Saves attendance to the central database.

HOW TO OPERATE:
1. Select class arm.
2. Tap "Mark All Present" or tap individual status buttons for each student.
3. Add remarks for absent or late students if necessary.
4. Click "Submit Attendance".

4. MY CLASSES & SUBJECT ASSIGNMENTS (`/teacher-dashboard/profile-edit`)
================================================================================
OVERVIEW:
Enables educators to review their assigned class arms, view enrolled student lists,
and configure subjects taught.

KEY FEATURES & CONTROLS:
- Assigned Classes Card: List of classes where the user is designated as class teacher or subject teacher.
- Subject Roster List: Mathematics, English, General Science, etc.
- Enrolled Student Roster: View photos, IDs, and parent contact details for students in assigned classes.

HOW TO OPERATE:
1. Navigate to the "Work & Classes" section of your profile.
2. Review assigned class rosters and verify enrolled student count.

5. TEACHER TIMETABLE & SCHEDULE (`/teacher-dashboard/teacher-timetable`)
================================================================================
OVERVIEW:
Displays the educator's personal weekly teaching schedule, highlighting class periods,
subject locations, break times, and free periods.

KEY FEATURES & CONTROLS:
- Day Selector Tabs: Monday through Friday schedule view.
- Period Cards: Period number, start/end time, subject title, and assigned class arm (e.g. 08:30 AM - Period 1: Maths - JSS 2 Gold).
- Next Class Highlight: Visual indicator for the upcoming period.

HOW TO OPERATE:
1. Tap day tabs (e.g. "Wednesday") to view that day's lecture schedule.
2. Check class locations and period timings.

6. CLASSROOM TIMETABLE MANAGEMENT (`/teacher-dashboard/manage-timetable`)
================================================================================
OVERVIEW:
Allows class teachers or academic coordinators to build, edit, and publish weekly
class schedules for students.

KEY FEATURES & CONTROLS:
- Class Selector: Choose class arm to manage.
- Grid Builder: Assign subjects, teachers, and time slots for each period.
- Break Time Inserter: Add recess, lunch break, or assembly slots.
- Save & Publish Button: Pushes updated schedule to student and parent portals.

HOW TO OPERATE:
1. Select class arm.
2. Tap a period cell, select subject and educator from dropdowns.
3. Click "Publish Timetable".

8. WEEKLY TOPICS & LESSON PLANNING (`/teacher-dashboard/weekly-topics`)
================================================================================
OVERVIEW:
A curriculum mapping tool where teachers outline weekly topic objectives, learning
materials, and scheme of work for the entire term.

KEY FEATURES & CONTROLS:
- Term & Week Selector: Select Week 1 through Week 12.
- Subject Selector: Choose assigned subject.
- Topic & Sub-Topic Form: Enter Main Topic, Sub-Topic, Objectives, Teaching Aids, and Homework Summary.
- Submission Status: Mark scheme of work as "Draft" or "Submitted to Admin".

HOW TO OPERATE:
1. Select subject and target week (e.g., Week 3).
2. Fill in topic details and learning objectives.
3. Tap "Submit Lesson Plan".

9. TERM SCORE & GRADE RECORDS (`/teacher-dashboard/student-academic-records`)
================================================================================
OVERVIEW:
The primary grade entry console where teachers record Continuous Assessment (CA) scores
and Examination marks for students.

KEY FEATURES & CONTROLS:
- Class & Subject Selection: Filter roster by class arm and subject.
- Grade Input Table:
  * 1st CA Score (e.g., max 15)
  * 2nd CA Score (e.g., max 15)
  * Exam Score (e.g., max 70)
  * Calculated Total (auto-computed sum)
  * Grade Interpretation (auto-assigned A, B, C, D, F)
- Excel / Bulk Import Option: Upload scores using a formatted spreadsheet template.
- Submit to Admin Button: Lock grades for administrative review.

HOW TO OPERATE:
1. Select class arm, term, and subject.
2. Input 1st CA, 2nd CA, and Exam marks for each student.
3. System automatically calculates totals and assigns letter grades.
4. Click "Submit Grades to Admin".

================================================================================

11. BEHAVIORAL REMARKS & CONDUCT LOGS (`/teacher-dashboard/preschool-remarks`)
================================================================================
OVERVIEW:
Evaluates non-academic growth, including affective traits (punctuality, neatness,
honesty, relationship with peers) and psychomotor skills (handwriting, sports, craft).

KEY FEATURES & CONTROLS:
- Student Selector: Choose student from assigned class.
- Rating Scale Grid (1 to 5):
  * 5 = Excellent
  * 4 = Good
  * 3 = Fair
  * 2 = Poor
  * 1 = Very Poor
- Behavioral Category Ratings: Punctuality, Neatness, Politeness, Leadership, Sports, Musical Skills.
- Custom Behavioral Comment: Free-text field for observational notes.

HOW TO OPERATE:
1. Select student.
2. Tap numeric rating scores for each behavioral skill.
3. Click "Save Conduct Evaluation".

KEY FEATURES & CONTROLS:

23. SHARED STAFF OPERATIONS
================================================================================
a. STAFF ATTENDANCE GPS CHECK-IN (`/shared/scan-attendance`)
   - Overview: GPS location and QR code clock-in tool for staff daily arrival verification.
   - Operations: Open screen, tap "Check In Now", system checks campus geofence perimeter, records timestamp, and updates attendance log.

b. DAILY FINANCIAL OPERATIONS (`/shared/daily-financials`)
   - Overview: Daily collection console for staff assigned fee collection roles.
   - Operations: Select Fee Type (Feeding, Bus, Extra Class), search student, mark payment, and generate collection ledger entry.

c. DAILY LEDGER VIEW (`/shared/daily-ledger`)
   - Overview: Real-time itemized list of fee payments recorded today.
   - Operations: Review daily collection totals.

d. FEEDING FEES COLLECTION (`/shared/feeding-fees`)
   - Overview: Specialized desk to collect and verify daily or weekly student feeding fees.
   - Operations: Check off students participating in lunch program and record fees.

e. BUS FEES COLLECTION (`/shared/bus-fees`)
   - Overview: Manage shuttle transport payments and verify bus pass validity.
   - Operations: Mark student transport dues as paid.

f. EXTRA CLASSES FEES COLLECTION (`/shared/extra-classes-fees`)
   - Overview: Record payments for after-school extra lessons.
   - Operations: Search student name and record lesson fee payment.

g. CODING & ROBOTICS HUB (`/coding-robotics`)
   - Overview: STEM instructional portal for robotics projects, coding exercises, and logic games.
   - Operations: Select lesson module and guide students through interactive exercises.

h. ACADEMIC CALENDAR (`/academic-calendar`)
   - Overview: Institutional calendar detailing term start/end dates, exam weeks, and holidays.
   - Operations: View upcoming academic events and term dates.
